# سامانه جامع آزمایشگاه تشخیص طبی

نسخه اولیه قابل اجرا برای مدیریت فرایند پذیرش، آزمایش‌ها، ورود نتیجه و تأیید مسئول فنی با Django.

## اجرا

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

سپس به `/admin/` وارد شوید، چند آزمایش بسازید و از صفحه اصلی پذیرش ثبت کنید.

## فرایند کاری

1. پذیرش بیمار و انتخاب آزمایش‌ها
2. ثبت نتیجه توسط کاربر آزمایشگاه
3. ارسال سفارش به وضعیت «در انتظار تأیید»
4. تأیید نهایی توسط کاربر staff/مسئول فنی

این نسخه هسته MVP است. پیش از استفاده عملیاتی باید احراز هویت اختصاصی بیماران، PDF امن، پیامک، پرداخت، ثبت لاگ تغییرات، پشتیبان‌گیری، تست‌های خودکار و الزامات قانونی حریم خصوصی اضافه شود.
